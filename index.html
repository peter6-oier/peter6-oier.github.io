题解：AT_abc407_c [ABC407C] Security 2

发表于 2025-12-04 更新于 2026-10-24

题目背景

有一个密码输入设备，初始显示空字符串 t，支持两种操作：

  • 操作 A：在 t 末尾追加字符 0。
  • 操作 B：将 t 中所有数字替换为下一个数字。

给定目标字符串 S，要求从空字符串开始，通过最少次数的操作得到 S，输出最小操作次数。

核心规律

从操作逻辑可推导：

  • 第 i 位的目标数字为 d，累计B操作次数为 k ，则该位需要的额外 B 操作次数为 m = (d - k) % 10。

思路

  1. 从字符串最后一位向前处理，因为后添加的位不会被先添加的位的 B 操作影响，符合操作顺序逻辑。
  2. 用 k 记录累计的 B 操作次数，反映前面位的 B 操作对当前位的偏移影响。
  3. 对当前位目标数字 d，计算需要补充的 B 操作次数 m。

题解：AT_abc405_c [ABC405C] Sum of Product

发表于 2025-12-04 更新于 2026-10-24

公式

计算 $\displaystyle \sum_{1\leq i<j\leq N} A_iA_j$ 的公式为：

$$
\sum_{1 \leq i < j \leq N} A_i A_j = \frac{1}{2} \left( \left( \sum_{i=1}^N A_i \right)^2 - \sum_{i=1}^N A_i^2 \right)
$$

推导

先将所有元素和的平方分解一下：

$$
\left( \sum_{i=1}^N A_i \right)^{2} = \sum_{i=1}^N A_i^2 + 2 \sum_{1 \leq i < j \leq N} A_i A_j
$$

然后，我们发现后面那一项包含了题目的求式，所以把它提出来：

$$
2 \sum_{1 \leq i < j \leq N} A_i A_j = \left( \sum_{i=1}^N A_i \right)^2 - \sum_{i=1}^N A_i^2
$$

接着再化简：

$$
\sum_{1 \leq i < j \leq N} A_i A_j = \frac{1}{2} \left( \left( \sum_{i=1}^N A_i \right)^2 - \sum_{i=1}^N A_i^2 \right)
$$

就得到公式了。

分析题目

  • 操作 1：在顶点 $u$ 和 $v$ 之间添加一条无向边。
  • 操作 2：确定顶点 $v$ 是否可以通过边从顶点 $u$ 到达。
  • 操作 3：查询能否到达黑色节点。

分析样例

块状数组

发表于 2025-10-31 更新于 2026-10-24

块状数组

前置知识：

  • 分块思想（可见 这个） 。
  • 懒标记的思想（线段树） 。

块状数组的思想

块状数组是一种将分块思想运用到数组的数据结构，

它把长为 $n$ 的数组均分为约 $\sqrt{n}$ 个块，每块约 $\sqrt{n}$ 个元素。

它能快速处理区间问题，比如：

  • 区间加减；
  • 区间求和；
  • 区间最大值/最小值查询。

块状数组的实现

建立块状数组

根据数组的长度确定块的大小和数量，同时明确各块起止下标及元素归属，预处理块和。

区间修改

这里给出两种懒标记的写法：显性懒标记和隐性懒标记。

显性懒标记

核心思路

块状数组的分块结构可以类比为一棵深度为 $3$ 的满二叉树（每个非叶子节点有 $2$ 个子节点），其中：

  • 根节点表示整个数组（$1$ 个块）。
  • 中间层表示分块（约 $\sqrt{n}$ 个块）。
  • 叶子节点表示单个元素（$n$ 个元素）。

与线段树的懒标记思路相同，对完整块的修改操作（如区间加法、乘法）不立即更新块内的具体元素，

而是将修改操作存在一个标记数组（如 $add$ 和 $mul$）中。

示例：给完整块整体加 $val$，只需将该块的懒标记加上增加的值，而不需要再遍历块内每个元素。

给完整块整体加 $val$，只需将该块的懒标记加上增加的值。

当需要访问完整块的元素时：

  • 先将标记下传给块内元素。
  • 再进行后续操作。

对于完整块直接更新懒标记 $add_{i} \gets add_{i}+val$。

对于不完整块，先下传标记，再暴力修改元素值。

隐性懒标记

核心思路

不使用单独的标记数组记录和修改，而是将对完整块的修改延迟到访问元素时动态计算。

示例：若某完整块需要加 $val$，不记录标记，而是在访问该块元素时，直接返回元素原值与累计的修改值的和。

每个块维护一个懒标记，表示块整体的增量的和。当访问块内元素 $a_i$ 时，其实际值为块内元素与块整体的增量的和。

对完整块的修改只需更新 $add_{blk}$，无需遍历元素。

对不完整块的修改需先将 $add_{blk}$ 下传给元素，再修改元素值。

不适用于查找最大值和最小值。

查询时，元素实际值为 $a_{i}+add_{blk}$；

修改完整块时只需更新 $add_{blk}$；

修改不完整块时需要先下传标记。

区间查询

对于不完整块，直接暴力计算 $a_{i}+add_{blk}$。

对于完整块，直接使用预处理的和 $sum_{i}+add {i}\times len{i}$。
